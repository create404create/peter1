How It Works
  1. Upload your .txt file with phone numbers (one per line)
  2. Basic Validation checks if numbers are valid US format
  3. DNC Check verifies each number against Do Not Call lists
  4. Person Data retrieves name, address, and other information
  5. Download separate files for clean and DNC numbers with complete data
