How to Use
  1. Prepare a .txt file with one phone number per line
  2. Upload the file using the upload area

Tips & Information
  • Maximum file size: 100MB (approx. 1 million numbers)
  • Supported formats: 10-digit US phone numbers
  • Processing speed: 50-100 numbers/second
  • Data includes: Name, address, DNC status, carrier info
  • Export formats: CSV, JSON, Text Report
